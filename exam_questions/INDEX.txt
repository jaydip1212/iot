COMMON NOTES
------------
- Use Arduino Uno and the components listed in each question.
- The examples treat IR LOW (0) as object detected. Confirm the module behavior.
- Calibrate each LDR threshold. Divider/module wiring can make readings rise or fall as light decreases.
- Timed sessions use millis() so the program can keep checking sensors.
- LCD sketches use LiquidCrystal_I2C at address 0x27; install that library if needed.
